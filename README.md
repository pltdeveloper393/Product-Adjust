# Product ADJust

Адаптивное мобильно-ориентированное веб-приложение для продавцов маркетплейсов:
с его помощью можно быстро генерировать карточки товаров (название, описание,
SEO-ключи и изображения) с использованием ИИ.

Проект выполнен в рамках лабораторных работ по дисциплине
«Разработка мобильных приложений» (КБиП, 2026–2027).

## Возможности

- вход в аккаунт;
- главный экран со списком товаров и статистикой;
- экран деталей товара с SEO-ключами и площадками;
- ИИ-чат с ассистентом.

## Технологии

- семантический HTML5;
- CSS Flexbox, стратегия **Mobile First**, медиа-запросы (480 / 768 / 1024 px);
- относительные единицы (`rem`, `%`, `vh`, `clamp`);
- `normalize.css` для единообразия в браузерах;
- JavaScript без фреймворков;
- Font Awesome 6 и Google Fonts (Manrope) через CDN.

## Структура

```
index.html   home.html   product.html   chat.html
css/   normalize.css  normalize.min.css  style.css  style.min.css
js/    app.js  app.min.js
assets/  icon.svg  logo.svg
```

## Запуск

Открыть `index.html` в браузере. Сервер не требуется — все зависимости
подключены через CDN. Для публикации используется GitHub Pages.
